# AutoType Keyboard (Android)

यह ऐप आपके Android फ़ोन को Bluetooth कीबोर्ड बना देता है और आपका लिखा टेक्स्ट PC / TV / टैबलेट पर अपने-आप टाइप करता है।

## बनाने का तरीका
1. Android Studio (Koala या नया) में `AutoTypeKeyboard` फ़ोल्डर खोलें।
2. Gradle Sync होने दें (अगर Gradle version पूछे तो 8.7 या ऊपर चुनें)।
3. फ़ोन में USB debugging चालू करके फ़ोन जोड़ें, फिर **Run** दबाएँ।
   APK चाहिए तो: Build > Build APK(s)।

## इस्तेमाल
1. फ़ोन की Bluetooth सेटिंग में अपने PC/TV से एक बार पेयर करें।
2. ऐप खोलें, अनुमति दें, **कीबोर्ड चालू करें** दबाएँ।
3. सूची से डिवाइस चुनें और **जोड़ें** दबाएँ।
4. टेक्स्ट, देरी, दोहराने की संख्या और अंतराल भरें।
5. **ऑटो-टाइप शुरू** दबाएँ, फिर शुरू होने से पहले के इंतज़ार में PC पर टेक्स्ट बॉक्स में क्लिक करें।
6. रोकने के लिए **रोकें** या नोटिफ़िकेशन का Stop बटन दबाएँ।

## सीमाएँ
- Android 9 (API 28) या ऊपर चाहिए।
- कुछ फ़ोन (कुछ Samsung/Xiaomi मॉडल) Bluetooth HID Device सपोर्ट नहीं करते। हर फ़ोन पर टेस्ट करना होगा।
- सिर्फ़ English (US) कीज़ टाइप होती हैं। हिंदी और इमोजी टाइप नहीं होंगे, उन्हें छोड़ दिया जाता है।
- कुछ फ़ोन पर पेयरिंग के बाद भी "जोड़ें" के लिए PC की तरफ़ से कनेक्ट करना पड़ सकता है।

## फ़ाइलें
- `HidManager.kt`: फ़ोन को कीबोर्ड के रूप में रजिस्टर करना और key भेजना
- `HidKeyMap.kt`: अक्षर को HID key code में बदलना
- `TypingService.kt`: बैकग्राउंड में दोहराव, अंतराल और देरी के साथ टाइपिंग
- `MainActivity.kt` और `activity_main.xml`: स्क्रीन और अनुमतियाँ
